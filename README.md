# 🎨 ML Color Harmony

A student project for an assignment for "Machine Learning for Design" module.

*Note: The language is in both English and Vietnamese.*

## 📌 Introduction

The application uses **Random Forest Regressor** algorithm to predict the harmony of color combinations (3-5 colors) based on color theory (Analogous, Complementary, Split Complementary, Triad, Monochromatic). This project aims to support designers in choosing color palettes more effectively.

## 🚀 Features

- Select colors intuitively using the color picker.
- Analyze light/dark contrast.
- Predict "harmony score" on a scale of 10.

## 📦 Installing & Running

1. Clone the repository:

```
git clone https://github.com/chairman-q/ML-color-harmony.git
```

1. Create a virtual environment:

```
python -m venv venv
```

1. Install the library:

```
pip install -r requirements.txt
```

1. Run the app:

```
streamlit run app.py
```
